# RARE QUEST — новый сайт

## Состав
- `index.html` — страницы сайта и окно подробностей квеста
- `style.css` — оформление и адаптация под телефон
- `app.js` — список квестов и интерактивность карточек
- `assets/hero-cover.png` — обложка «Страшные переписки»
- `assets/owners.jpg` — фотография двух владелиц

## Публикация на Vercel через GitHub
1. Распакуйте ZIP на телефоне.
2. Создайте новый репозиторий GitHub с названием `rare-quest-new`.
3. В репозитории нажмите Add file → Upload files.
4. Загрузите три файла из корня (`index.html`, `style.css`, `app.js`) и README. Затем откройте Add file → Upload files и загрузите обе фотографии в папку `assets` (создайте папку `assets`, если нужно).
5. Сделайте Commit changes.
6. В Vercel: Add New → Project → Import Git Repository → выберите `rare-quest-new` → Deploy.

## Уже работает
- Главная страница с анимированным заголовком.
- Секция квестов и открытие карточки с описанием, временем, возрастом и сложностью.
- Обложка сверху с растворением в фон.
- Фото владелиц внизу, ссылки на Telegram и TikTok.
- Адаптация под мобильные устройства.

## Важно
Кнопка «Начать квест» пока демонстрационная. Для настоящего прохождения нужны серверная часть, регистрация, база данных, realtime-чат и защищённая админка с отдельными аккаунтами двух владелиц. Сейчас изменения в списке квестов не управляются через полноценную общую админку.
