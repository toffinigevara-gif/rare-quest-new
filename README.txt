RARE QUEST — обновлённый комплект сайта

ЗАГРУЗКА:
1. Распакуйте архив на устройстве.
2. В GitHub откройте репозиторий.
3. Add file → Upload files.
4. Загрузите содержимое папки rare-quest-upload (index.html, admin.html, CSS/JS и папку assets).
5. Нажмите Commit changes.
6. Дождитесь автоматического обновления Vercel.

Что работает: адаптивная главная страница, карточки, просмотр описания, демо-панель /admin.html с добавлением/изменением/удалением карточек.
Важно: квесты в панели сейчас сохраняются только в localStorage браузера. Это не общая база. Регистрация, чат, аккаунты владельцев, загрузка файлов через админку и визуальный редактор трёх секций ещё не подключены. Для них нужна серверная база и авторизация (например, Supabase).
